# The Tin Files audio assets

Upload the six production audio clips into this folder using these exact filenames:

- `knock-slow.mp3`
- `knock-regular.mp3`
- `knock-rapid.mp3`
- `knock-playful.mp3`
- `knock-panicked.mp3`
- `phone-ring.mp3`

`phone-ring.mp3` should be edited so its start/end loop cleanly because the app repeats it continuously until **Answer Phone** is pressed.

No Cloudflare Worker is needed for this app. These are static shared assets served directly from GitHub Pages.
