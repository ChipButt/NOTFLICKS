GitHub publishing access

To publish the shared library from this browser, use a fine-grained GitHub personal access token restricted to ChipButt/NOTFLICKS with Contents: read and write. The token is stored only in this browser and is never written to the repository.

Create a fine-grained token on GitHub. Give it access only to the NOTFLICKS repository and set Repository permissions → Contents → Read and write.
